# Study Hub 🚀
> A modern, full-stack educational web platform.
🔗 **Live Demo:** [study-hub-ybmb.vercel.app](https://study-hub-ybmb.vercel.app/)
## 💻 Tech Stack
- **Frontend:** React, Next.js, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Deployment:** Vercel
## ✨ Key Features
- ⚡ **Highly Responsive UI:** Pixel-perfect component architecture with a modern dark mode interface.
- 🧠 **Smart Workflows:** Features full-screen strict Pomodoro blockers and AI-assisted chat tools.
- 📊 **State Management:** Seamless API integrations and complex state handling.
